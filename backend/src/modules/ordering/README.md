# ordering

Cart to order, mixed fulfilment modes per item, merchant accept / reject, 10-minute response deadline, out-of-stock handling.

Requirements: FR-2.1 to FR-2.6, FR-5.5, FR-5.6 (see `docs/requirements`).

Suggested files: `ordering.routes.ts`, `ordering.service.ts`, `ordering.repository.ts`, `ordering.schema.ts`, `ordering.test.ts`.
